# Example cases

Hand-written example case files for the FOIA pack. They are examples, not
records of real requests. `clean-partial-grant.json` evaluates to a proof.
`late-denial-without-names.json` evaluates to reasons: the determination came
after the twenty-working-day period, the denial notice names no one, and the
notice states no reasons.

Run one with:

    compiled-ai run packs/foia packs/foia/cases/clean-partial-grant.json
